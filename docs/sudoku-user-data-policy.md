Privacy Policy for Swift Lab Sudoku

​1. Data Collection and Storage Architecture
​Swift Lab Sudoku is engineered with a privacy-first architecture. The application stores gameplay state, daily challenge progress, user statistics (e.g., solving times, success rates), and UI preferences (e.g., Light/Dark mode, color themes) strictly on the local file system of your device. We do not provision external databases to offload, monitor, or harvest user-generated telemetry or application state.
