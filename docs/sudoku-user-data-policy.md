# Privacy Policy for Swift Lab Sudoku

**Effective Date:** October 20, 2026

### 1. Data Collection and Storage Architecture
Swift Lab Sudoku is engineered with a privacy-first architecture. The application stores gameplay state, daily challenge progress, user statistics (e.g., solving times, success rates), and UI preferences (e.g., Light/Dark mode, color themes) strictly on the local file system of your device. We do not provision external databases to offload, monitor, or harvest user-generated telemetry or application state.

### 2. Personally Identifiable Information (PII)
The application operates completely offline and does not require user authentication or account creation. We do not collect, store, transmit, process, or sell any Personally Identifiable Information (PII), including but not limited to names, email addresses, geographic location, or hardware identifiers.

### 3. Third-Party Services and Telemetry
The core application operates without external tracking SDKs, advertising networks, or third-party analytics integrations. Any data collection related to crash reports or installation metrics is strictly governed by the distribution platforms (Apple App Store / Google Play Store) based on the diagnostic opt-in settings configured at the operating system level by the user.

### 4. Data Retention and Deletion
All analytical data and saved states are persistently retained only on the local device hardware. The user exercises absolute control over this data lifecycle. Application data can be permanently purged by clearing the application cache/storage via system settings or by completely uninstalling the binary from the device.

### 5. Data Security
We rely exclusively on the native application sandboxing mechanisms provided by the host operating system (iOS/Android) to encapsulate and protect local application data against unauthorized access or tampering from external processes.
